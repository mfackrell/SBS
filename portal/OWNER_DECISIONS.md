# Owner decisions checklist

The build brief requires these decisions before or during production rollout.

- [ ] Final role permissions matrix: confirm exactly what owner, staff, and client users may do.
- [ ] Proposal acceptance language: approve the exact legal text displayed and stored at acceptance.
- [ ] Proposal expiration defaults: decide whether new proposals should receive a default expiration date.
- [ ] File retention and deletion policy: define retention periods and whether soft-deleted metadata is retained indefinitely.
- [ ] Maximum upload size and final allowed file types: confirm the current 25 MB maximum and PDF/CSV/XLSX/DOCX/PNG/JPG list.
- [ ] Notification preferences: decide email/in-app notification cadence for invites, messages, requests, proposals, and close status.
- [ ] QBO billing link strategy per client: determine how SBS obtains and maintains each external QuickBooks link/reference.
- [ ] Portal branding details: approve logo treatment, colors, and fonts.
- [ ] Support contact text: provide the support email/phone or other contact wording to display in portal help states.
- [ ] MFA policy: decide whether MFA is required for staff only or all users.
- [ ] E-sign provider: decide whether a third-party e-sign provider should be added in a later phase.
- [ ] Document request templates: decide whether reusable request templates should be added in a later phase.
